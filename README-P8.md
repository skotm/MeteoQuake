# P8: 揺れ検知は止めず、地震タブ以外では「地図の自動移動」だけを止める

P6・P7・P7b 適用済みのリポジトリ直下へ上書きしてください(変更は src/App.jsx と src/app/MapCanvas.jsx)。

## 変更内容
- 気象・警報タブでの「揺れ検知の無効化」と、地図上のリアルタイム表示の非表示を廃止
  (揺れ検知・震度表示は、どのタブでも従来のB=KyoshinViewerと同じく動き続ける)
- タブ切り替え時の「2秒間の検知無効」を廃止(MapCanvas.jsx から該当処理を削除)
- 地震タブ以外(津波・気象・警報・設定)では、次の2つの自動移動を無効にする
  - 揺れ検知の視点追従(shakeFollow)
  - 緊急地震速報の自動ズーム(eewFocus)
  地震タブ(リアルタイム/地震一覧/地震検索)では、設定「カメラの動き」に従う。
  設定画面の値そのものは変えない。地震タブ以外の間に届いた速報は「見た」扱いになるので、
  地震タブへ戻った時に古い速報で急に動かない
- P7b の調査用ログ(debugCameraMoves)は削除

## 変更しなかったもの
- P6 の「東京首都圏の検知しきい値の引き上げ」(shakeDetection.ts)はそのまま
