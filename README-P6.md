# P6: 東京首都圏の揺れ検知しきい値の引き上げ / 気象・警報タブ後の検知2秒無効化

## 変更内容
1. 東京首都圏の観測点だけ、上昇系の検知しきい値を実質1.5倍に引き上げ(shakeDetection.ts)
   - 範囲: 緯度 35.2〜36.1 / 経度 138.9〜140.5 の矩形(東京・埼玉・千葉北部・神奈川東部ほか)
   - 方法: その範囲の観測点は、「前tickとの差」「直近5秒平均との差」を 1.5 で割ってから、
     すべての上昇系しきい値(reaction/rise/isolated/propagation/broadRiseCandidate など)と比べる。
     震度の値そのものと、震度による段階分け(levelThresholds)は変えない
   - 調整: DEFAULT_SHAKE_DETECTION_PARAMS.regionalRiseScales の scale(1.5)と範囲を書き換える。scale=1 で無効
   - テスト: 同じ「+0.6」の上昇が、首都圏の観測点では 0.4、大阪の観測点では 0.6 として扱われることを確認済み
2. 気象タブ・警報タブでは、揺れ検知(通常方式・グリッド方式とも)を無効にする
   - (P4/P5 で通常方式は無効化済み。今回、グリッド方式も同様に無効化)
3. 気象・警報タブから他のタブへ移った時は、検知を2秒間無効にする(MapCanvas.jsx)
   - 検知が「無効→有効」に戻った瞬間に、検知エンジンの履歴を破棄して2秒間は検知しない。
     この間も値の更新は続くので、2秒後からは通常どおり検知できる
   - 設定で「揺れ検知」をOFF→ONにした時も同じ動作になる
