# P9: 気象・警報タブでは、リアルタイム震度と更新時刻の表示を隠す

P8 まで適用済みのリポジトリ直下へ上書きしてください(変更は src/App.jsx と src/app/BottomDock.jsx)。

- 気象タブ・警報タブでは、次の表示を隠す(地図が気象・警報の情報だけになる)
  - 地図上のリアルタイム震度(観測点・上昇中の表示・揺れ検知のイベント表示・震源推定・グリッド表示)
  - 震度しきい値バー
  - リアルタイム震度の更新時刻のバッジ(と地震検知テスト実行中のバッジ)
- 揺れ検知・震源推定の「計算」は止めない(他のタブへ戻った時に検知が途切れない)
- 地図の自動移動(視点追従・EEWの自動ズーム)が地震タブ以外で止まる動作は P8 のまま
- 地震・津波・設定タブでは、従来どおり表示される
