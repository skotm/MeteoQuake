# 緊急地震速報・報更新処理 要件書の改訂箇所

「MeteoQuake 緊急地震速報・報更新処理 要件書」のうち、次の内容に改訂した箇所と、実装の対応(`src/app/simEewRules.js`)。

## 発表値と更新判定(2・3.2・3.3・6・9・10.1 を置き換え)

- 発表値(報に載せる値)は、Mが0.1刻み、深さが10km刻み(最小10km)。予想震度の計算も発表値で行う。
- 更新の判定は、**前回の報を出した時点の内部値**(丸める前の値)と、最新の内部値の比較で行う。
  - Mが±0.05以上変化したら更新する。
  - 深さが±5km以上変化したら更新する。
  - 境界値を含む。上昇・低下の両方が対象。
- 「変化量にかかわらず更新(最小閾値なし)」の記述は廃止。
- 内部値が上の閾値以上動けば、発表値が同じでも更新する(更新理由と履歴で変化が分かる)。
- 例: M4.0→4.1(内部差0.1以上)は更新する。深さ10→11kmは更新しない(内部差5km未満)。深さ10→30kmは更新する。

## そのほかの更新条件(要件書どおり)

- 震源位置: 緯度・経度を独立に判定。内陸0.2度以上、海域0.4度以上(陸域は都道府県データで判定)。
- 最大予測震度(計測震度): +0.5以上、または-1.0以上。
- 予報区: 新たに震度4以上になった予報区の追加、震度4以上の予報区の1階級以上の変化(震度4未満への低下を含む)。
- 警報の続報: これまで警報対象でなかった予報区に、新たに震度5弱以上が予測された時だけ。
- 最大予測長周期地震動階級・予報区ごとの長周期地震動階級: シミュレーションに計算が無いため、当面は判定しない(枠のみ)。
- 複数条件が同時に成立しても報は1つ。更新理由は全て記録する(2つ以上なら「複数条件の同時成立」も記録)。

## 発表条件・警報・終了(要件書に記載がなかったため追加)

- 予報の発表: 推定M3.5以上、または最大予測震度3以上。(観測点の振幅100ガル以上は、加速度が無いため対象外)
- 警報: 2観測点以上かつ最大予測震度5弱以上。警報地域は、予測が下がっても取り消さず、保持した最大値で表示する。
- 終了: 最初の検知から600秒、または、揺れが収まって一定時間たった時(数値は仮置き)。最終報の表示にするだけで、報番号は増やさない。
- 取消: 誤検知(推定イベントの消失)と、手動停止のみ。
- 定時報は設けない。

## ハイブリッド(IPF法相当の推定+PLUM法)

- 地域ごとの予想震度は、通常方式とPLUM法の大きいほうを採用する。PLUM法だけの報は出さない。
- 合成後の予想震度に対して、上の更新条件を判定する(PLUM法専用の更新判定は無い)。

## レベル法(震源要素によらない予測手法)の擬似再現

出典: 気象庁「緊急地震速報の概要や処理手法に関する技術的参考資料」(2024年4月11日)。

- 観測点の揺れが一定以上になったら、震源・Mの推定を待たずに、「観測点近傍で震度5弱程度以上」の予報を直ちに出す。
  - 気象庁は観測点の上下動加速度100gal以上。加速度の無いシミュレーションでは、計測震度4.5以上(ほぼ100gal)で代用する。
- 載せる情報は震度5弱程度以上の予報区(観測点が属する細分区域)のみ。震源・M・到達予測時刻は載せない。警報にはしない。
- すでに震度5弱以上で報に含まれている地域の揺れでは、新たに発表しない。含まれていない地域で強い揺れがあれば、その地域を加えた続報を出す。
- 通常方式の推定が発表条件を満たした時、同一の地震(レベル法の観測点が推定の検知点に含まれる、または予報区が重なる)なら、レベル法の報を通常方式の続報として引き継ぐ(報番号は続ける)。
- 所定の時間内に2地点目の観測点を検知できなければ、取り消す。時間は資料に数値が無いため仮置き(10秒)。
- PLUM法だけの報は、引き続き出さない。

## 1観測点だけの結果による報

- 1観測点だけの推定結果による報には、予測震度(最大・予報区別)を載せない。警報にもしない。

## ログ

- 報の更新理由・更新前後の値は、EEWカード(フローティング)には出さず、地震検知テストパネルの連動セクションのログにまとめる。
- ログはセッション中のみ保持し(上限500件)、アプリの履歴・通知・保存には流さない。コピーとクリアができる。
- 記録する内容: 開始、発表、更新(理由・更新前後の値)、最終報、取消、停止、実EEWによる中止。レベル法の報にも「レベル法」と付ける。

## PLUM法のトリガ閾値について

資料にはPLUM法のトリガ閾値の数値が無い。既定の観測震度5弱(計測震度4.5)は仮置きで、気象庁の運用値ではない(`PLUM_MIN_OBSERVED_INTENSITY`)。

## 閾値の定数

すべて `src/app/simEewRules.js` の `EEW_RULES` に集約している(「仮置き」と書いたものは資料に数値が無い値)。
