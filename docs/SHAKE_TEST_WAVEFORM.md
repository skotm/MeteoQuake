# 地震検知テストの波形モデル(現実的モデル)

実装: `src/engines/shakeTestWaveform.ts`(生成器は `shakeTestSimulation.ts` の `prepareShakeTest`)。

## 位置づけ

- 既定は現実的なモデル(`model: "realistic"`)。以前の簡易版(台形・全国一律の地盤・点震源)は `model: "simple"` で選べる(エンジンの回帰テスト用)。
- **震源推定・揺れ検知が使うモデルは変更していない**(`calcPeakIntensity`、`createPeakIntensityModel`、`P_WAVE_SPEED_KM_S`、`S_WAVE_SPEED_KM_S`)。
  テスト波形だけを現実的にし、推定が「実際とは少し違うモデル」で解くことで、実際の運用に近い誤差が出る。

## 出典

- 最終震度の式・地盤増幅・P波/S波速度・有限断層の考え方: WE-Simulator(https://github.com/itachi-kun-itc/WE-Simulator)の計算を参考にした。
  リポジトリにライセンス表記が無かったため、コードは転記せず、式と考え方を書き直している。
- 揺れが収まる過程(減衰)・平常時の揺らぎ・P波の段階や立ち上がりの形: MeteoQuake独自の暫定モデル(WE-Simulatorには無い部分)。

## モデルの内容

- 最終震度 = 1.43M − 0.32(M−7.4)²(M7.4超) − 2.12log10(R+20) − 0.0042R + 地盤補正 − 0.95(上限7。下限は丸めない)
- 地盤補正(−0.45〜+0.75): 最寄り(40km以内)の気象庁観測点のARV・AVS30(`stations_with_amp_revised.json`)から求める。無ければ補正なし。
- 走時: P波6.5km/s、S波3.8km/s。
- 有限断層(M6.6以上): 震源を破壊の開始点として、走向の線上に断層(長さ 10^(−2.44+0.59M) km、最大520km)を置き、12km以上の間隔・最大16区間の小震源に分ける。
  破壊速度は既定2.8km/s。破壊の向き(両側/走向の向き/逆)・走向・速度は、フォームの「断層の設定(M6.6以上)」で変えられる。
  到達時刻・震源距離は、最も近い小震源で決める。小震源のS波の到達時刻の差の分だけ、揺れの継続が延びる。
- 時間波形(観測点ごと):
  - P波の段階: 最終震度の割合(M・地盤で変わる)。上限は約2.4(震源が近いと約3.0)。約0.7秒の素早い立ち上がりと、S波前の緩やかな上昇。
  - S波の立ち上がり: 主動の急な立ち上がりのあと、緩やかにピークへ。距離・地盤の柔らかさ・Mで時間が変わる。
  - ピーク後: 強い揺れの間は最大付近で、周期の異なる強弱(複数のピーク)がある。その後、2成分で減衰して平常値に戻る。継続時間はM・距離・海域で伸びる。
  - 観測点ごとの固定の揺らぎ(ピークの±0.2程度、到達時刻の数百ms、平常時の小さな揺らぎ)。同じ入力なら毎回同じ結果。
- 最終震度が平常値(−3)以下になる観測点は、データなし(弱い地震が全国に広がらない)。

## 仮置きの値

減衰の時間スケール、P波の割合、立ち上がり時間の係数などは、WE-Simulatorにも資料にも数値が無いため、見た目の自然さで決めた暫定値。
実際の観測波形(リプレイ)で較正できる(`buildWaveProfile` の係数)。
